# Maduración y Vendimia — vista previa de diseño (no indexar)

Archivos estáticos ya compilados de dos propuestas de web para Maduración y Vendimia, S.L. (prototipo de ATELIER):

- `/a/` — Web A, paleta propia.
- `/b/` — Web B, con los colores y tipografías actuales de la marca.

No es la web oficial. No procesa pedidos ni pagos y no guarda datos personales. Todas las páginas llevan `noindex, nofollow`.
Imágenes, etiquetas y textos: © Maduración y Vendimia, S.L., usados solo para esta vista previa.
Código de terceros incluido en el JS compilado: three.js (MIT) y GSAP (licencia estándar gratuita). Fuentes: DM Sans, Newsreader, Gloock y Schibsted Grotesk (SIL OFL 1.1).
