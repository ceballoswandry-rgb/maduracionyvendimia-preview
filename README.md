# Maduración y Vendimia — vista previa de diseño (no indexar)

Archivos estáticos ya compilados de las propuestas de web para Maduración y Vendimia, S.L. (prototipo de ATELIER):

- `/c/` — Web C «Bodega cinematográfica» (recomendada).
- `/a/` — Web A, paleta propia (versión anterior).
- `/b/` — Web B, con los colores y tipografías actuales de la marca (versión anterior).

No es la web oficial. No procesa pedidos ni pagos y no guarda datos personales. Todas las páginas llevan `noindex, nofollow`.
Imágenes, etiquetas y textos: © Maduración y Vendimia, S.L., usados solo para esta vista previa.
Código de terceros incluido en el JS compilado: three.js (MIT), GSAP (licencia estándar gratuita) y, en C, Lenis (MIT). La web C reimplementa patrones de Codrops (MIT); avisos completos en `c/LICENCIAS-TERCEROS.txt`. Fuentes: DM Sans, Newsreader, Gloock y Schibsted Grotesk (SIL OFL 1.1).
